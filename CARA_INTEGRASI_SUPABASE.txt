================================================================================
                    PANDUAN INTEGRASI SUPABASE - FUNDLY.ID
================================================================================

Ringkasan langkah (panduan lengkap: server/SUPABASE_SETUP_GUIDE.md)

1. Buat proyek di https://supabase.com (region Singapore disarankan).

2. Salin .env.example menjadi .env lalu isi:
     VITE_SUPABASE_URL=https://xxxxxxxx.supabase.co
     VITE_SUPABASE_ANON_KEY=eyJhbGciOi...
     VITE_AUTH_PROVIDERS=google

3. Buka Supabase -> SQL Editor -> New Query, tempel SELURUH isi file
   server/schema.sql, lalu klik Run.
   (Aman dijalankan ulang & aman di atas skema lama. Folder sql/ versi lama
    sudah dihapus karena digantikan oleh server/schema.sql.)

4. Authentication -> URL Configuration:
     Site URL      : http://localhost:5173 (atau domain production)
     Redirect URLs : http://localhost:5173/**  dan  https://domain-anda/**

5. (Opsional) Aktifkan Google/Facebook/Apple di Authentication -> Providers,
   lalu sesuaikan VITE_AUTH_PROVIDERS.

6. Jalankan aplikasi:
     pnpm install
     pnpm run dev

Jika muncul halaman "Konfigurasi Belum Lengkap", periksa file .env lalu
restart dev server (Ctrl+C, kemudian pnpm run dev).
Jika muncul pesan "Skema database belum diperbarui", jalankan ulang
server/schema.sql di SQL Editor.
================================================================================
